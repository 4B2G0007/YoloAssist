## 問題證據

**沒有執行真實 YOLO 權重或 street4.mp4，未測 Windows 原生視窗、GPU 或 Raspberry Pi 硬體，未量測真實街景延遲或準確率。**

## 已知限制

0.30 讓較低信心框更早進分析，也增加候選；2/5 減少一次推論等待，可能更易受抖動影響。不能保證圓形發光招牌、裝飾燈或高信心錯框完全不誤判。

無模型候選就無法畫出準確框；HSV 不掃全圖強猜號誌。小燈、模糊、閃爍、曝光或遮擋仍可能 UNKNOWN。960 只是比較解析度選項，可能降低處理 FPS。

青框與洋紅框不代表實際燈色。密集畫面仍可能標籤重疊；上緣框與狀態列可能局部相交。

請先用 README 的 --device 0 --stride 1 --no-record 指令驗收，再比較 960 或開啟錄影。持續慢時應比較畫面上方推論毫秒與候選首次出現位置，以區分硬體、模型漏檢與辨色拒絕。
